# O-NAUR: Observe, Notify, Audit, Update and Remediate

An LLM-powered agent that audits live web pages for UX quality and publishes structured reports to a dashboard.

## Installation
1. Run [workshop](https://github.com/canonical/workshop)

## Dashboard

A React + Vite app that visualises UX audit reports for ubuntu.com and canonical.com.

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.
